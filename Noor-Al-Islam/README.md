# نور الإسلام — مشروع أندرويد

تطبيق Android أولي بواجهة عربية لعرض مقاطع إسلامية في بطاقات عمودية مع السحب للأعلى، ومفضلة محلية ومشاركة الروابط. يشغّل الفيديو من خلال مشغّل YouTube الرسمي ولا ينزّل الفيديوهات.

## بناء APK
افتح تبويب Actions في المستودع وشغّل سير العمل Build Noor Al-Islam APK. بعد نجاحه نزّل artifact باسم Noor-Al-Islam-debug-apk وافتح الملف المضغوط لتحصل على app-debug.apk.

## ملاحظات
- هذا مشروع مصدر؛ ملف APK ينتج بعد نجاح البناء في GitHub Actions.
- يتطلب تشغيل المقاطع اتصالًا بالإنترنت.
- قد تتغير إتاحة مقاطع YouTube أو إعدادات التضمين.
