# بن عبادي للمواد الكهربائية — تطبيق أندرويد

تم رفع التطبيق الأصلي إلى هذا المستودع وتجهيزه للعمل داخل تطبيق Android عبر WebView.

## الحصول على APK
1. افتح تبويب **Actions** في المستودع.
2. اختر **Build Android APK**.
3. افتح أحدث عملية بناء بعد انتهائها.
4. نزّل **BinAbadi-Electric-debug-apk** من قسم Artifacts.
5. فك ضغط الملف على هاتف Android وثبّت `app-debug.apk`.

## ملاحظات
- APK الناتج نسخة Debug للتثبيت والتجربة وليس نسخة متجر موقعة.
- يحتفظ التطبيق بالبيانات محليًا على الجهاز. استخدم النسخ الاحتياطي بانتظام.
- ميزات الذكاء الاصطناعي السحابية تحتاج اتصال إنترنت ومفتاح API صالحًا.
